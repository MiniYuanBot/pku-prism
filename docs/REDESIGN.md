# 信息架构重设计

2026-10-12。沿用 DESIGN.md 的视觉系统，本轮验收以结构和操作路径为主。

## 真实页面问题

- 首页原生三列分别堆放工具、当前与历史课程、公告与组织。窄屏先出现九个工具入口；历史课程长列表挤占日常任务。
- 公告默认逐条完整展开，查找旧通知需要滚动多段正文。原生列表属于 announcementForm，不能为重排破坏表单归属。
- 教学内容与作业共用 content_listContainer；作业正文很长，首屏只能看到一个作业。标题是原生作业入口，附件与右键菜单具有原生行为。
- 原生课程侧栏有独立展开逻辑与课程自定义样式，保留其业务树比复制导航更可靠。

## 目标结构与交互

```text
首页
品牌 / 账户
工作区导航 | 我的课程                     | 公告与事务
全局入口   | 当前学期 / 历史课程 + 搜索    | 原生公告
工具       | 教师 / 学生分组              | 原生任务、组织
           | 课程卡片（名称、学期、编号） |

课程公告
原生课程导航 | 页面标题 / 原生筛选
             | 搜索 + 公告目录 | 所选公告全文、日期、来源
             |                 | 可切换全部展开

课程内容 / 作业
原生课程导航 | 页面标题
             | 搜索 / 实际条目数量 / 展开全部说明
             | 原生标题入口 · 类型 · 查看说明
             | 原生附件（直接可用）
             | 原生说明（按需展开）
```

首页执行较深的 DOM 重组，将全局导航容器、工具模块与课程模块移动到工作台；课程角色分组仍保留。公告增加目录组件，原生 form 与列表留在原位，局部插入双栏阅读布局。教学内容使用轻量行布局与搜索；只为含说明的条目增加 disclosure。手机改为单列，导航折叠、公告目录可展开、作业附件与标题始终可见。

手机页头显示来自原生面包屑的课程名称。Prism 外观控制在页头正常流中占据空间，避免遮住正文；桌面仍在右下角。原生标题区隐藏字段表单仍保留。仅消除公告开头的空白占位和附件列表继承的多余间距，正文与后续换行保持完整。

搜索仅过滤已加载的本页内容，明确显示匹配数量、无结果提示与清空入口。视图切换不发网络请求，不假设未加载课程、未读状态、完成进度或截止日期。原生课程、作业、下载链接是唯一业务入口。

## 实现边界

每个已识别页面建立独立 DOM 会话：移动时插入原位置占位节点；记录被改属性；所有自建节点与事件均登记清理。按相反顺序回滚，原生节点身份与嵌套事件容器保持不变。先检查关键结构，异常时立即回滚并保留基础样式。未知页保持原站。

不替换 innerHTML，不克隆业务表单，不拦截原生链接，不把原生表单移出原有祖先，不运行写入教学数据的动作。原站折叠状态、body class、URL 和认证存储不由 Prism 管理。

## 参考与取舍

- [Linear Concepts](https://linear.app/docs/conceptual-model)：不同视图组织同一批对象，视图不改变业务数据；用于当前 / 历史课程与本地过滤。
- [Notion sidebar](https://www.notion.com/help/navigate-with-the-sidebar)：导航与内容层级分离；用于首页工作区侧栏及窄屏 disclosure。
- [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/base/sidebar)：导航、分组、内容区独立组合；借鉴结构和可访问状态，不引入 React 依赖。
- [Canvas assignment index](https://community.instructure.com/en/kb/articles/661207-how-do-i-view-assignments-as-a-student)：作业索引承担浏览与进入详情的任务；本项目只展示实际 DOM 提供的标题、附件与说明，不伪造状态或日期。

## 验收方法

对比同一真实页面原生 / 新布局截图；检查首页课程优先和卡片列数、历史视图及搜索、公告选择和全部阅读、作业展开和附件。覆盖 375、768、1024、1440 宽度及浅深色，验证焦点与移动导航。浏览器回归核对链接 href、节点身份、表单归属、祖先事件可达，以及停用后原位置、属性、文本与节点顺序完全恢复。测试只做本地 UI 和只读导航。
