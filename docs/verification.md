## 本地检查

`npm run check` 通过：10 项测试、TypeScript 严格检查、Vite 生产构建及单文件 UserScript 校验。测试覆盖路由与 DOM 共同识别、排除登录 / 成绩 / 作业提交页、偏好回退、存储不可用、完整课程文字，以及嵌套移动的节点身份和顺序恢复、反复过滤后的属性恢复、原站后续更新的所有权、原区域被替换后不复活、监听器清理。

生产脚本约 76.8 kB，gzip 13.8 kB；包含所有 CSS，无运行时框架、CDN、字体或开发 URL。元数据在文件开头，classic script 解析和匹配范围校验通过。

## 原生功能与可逆性

在四个真实页面执行更新后的 `scripts/browser-smoke.js`；手机修复后四页再次通过：

- 当前 / 历史课程、局部过滤、无结果与清空状态；公告选择、全部阅读和阅读焦点；作业单项 / 全部展开。
- 搜索框 Enter 被阻止提交原生 form；自建按钮均为 type=button，无后端业务请求。
- 原链接节点持续连接，业务 href 不变；原表单及全部原控件的 form 归属不变；自定义无副作用探针事件仍可到达原课程列表、公告 form、内容列表祖先。
- 停用后逐节点核对原生父节点、全部子节点身份与顺序，以及 hidden、id、tabindex 属性和原课程 Text 节点，完全恢复。
- 停用偏好、重新启用、重复注入无重复节点、浅 / 深 / 系统主题、跨标签 StorageEvent 同步、销毁及监听器清理。
- 移动外观控制后先回滚布局再销毁控制，验证没有残留或复活的控制节点。

额外检查原生课程侧栏能展开和收起并恢复原状态。从已重组的首页实际点击原生课程链接，进入相应课程公告后返回；公告的“机构”筛选也完成原生搜索导航及 active 状态核验，再返回课程公告。首页手机工作区 disclosure 可操作，工具及全局入口仍可见。通过真实 Tab 键检查课程链接，`:focus-visible` 为主题色 2px 实线、2px 偏移。

语义 Token 保持上一版已验证的对比度：主文字浅 / 深 17.72 / 14.78，次级文字 7.73 / 6.34，品牌链接 7.59 / 8.16，控件边界 4.83 / 6.34。未对教师所有自定义富文本进行全面无障碍审计。
